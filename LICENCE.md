## 🧩 About

**ArcheAge Overlay Menu** is a curated list of ArcheAge open-source tools:

- **Overlays** — on-screen helpers, layout notes, HUD widgets, map pins
- **Quality-of-Life Helpers** — inventory notes, route planner, overlay notes
- **Research Notes** — exploration layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Exploration Helpers
- Route Notes — plan trade runs and farming loops
- Map Pins — mark gathering nodes and landmarks
- Resource Tracker — note ore, wood, and herb spawns
- Playback Notes — review movement routes for study

### 🎒 Inventory & Cosmetics
- Inventory Notes — organize gear, materials, and packs
- Costume Catalog — browse outfits, dyes, and mounts
- Glider Notes — compare glider stats and visuals
- Trade Pack Planner — plan pack trades between zones

### 🏋️ Combat & Class Study
- Skill Combo Notes — study class skill rotations
- Combat Log Helper — read and organize battle summaries
- Buff Tracker — note active buffs and timers
- Passive Tree Notes — plan skill point layouts

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Tab"` | Toggle overlay |
| `process_name` | String | `"ArcheAge.exe"` | Target process |
| `safe_mode` | Boolean | `true` | Keep conservative defaults |
